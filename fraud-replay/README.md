# Fraud Replay

Локальный симулятор расследования синтетических банковских переводов. FastAPI проверяет CSV, рассчитывает сигналы риска и сохраняет наборы в SQLite. Интерфейс React показывает активный набор, расследования, граф счетов и Replay.

## Запуск

Требуются Python 3.11+ и Node.js 22.12+. Команды в PowerShell выполняются из каталога `fraud-replay`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm.cmd ci
npm.cmd run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --port 8000
```

Интерфейс открывается на [127.0.0.1:8000](http://127.0.0.1:8000/), документация API на [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Для разработки оставьте API на порту 8000 и запустите `npm.cmd run dev` в другом терминале. На Linux и macOS используйте `.venv/bin/python` и `npm`.

При первом запуске открывается демонстрационный набор. Последний успешно импортированный набор сохраняется в `data/replay.sqlite3` и восстанавливается после перезапуска. Кнопка «Загрузить демо» создаёт новый активный набор с демонстрационными данными. Путь к базе можно задать через `FRAUD_REPLAY_DB`. Для русского PDF используется системный Arial или DejaVu Sans. При необходимости укажите путь к TTF через `FRAUD_REPLAY_PDF_FONT`.

## Импорт CSV

```csv
transaction_id,timestamp,sender,receiver,amount
TX-2041,2026-11-19T09:12:00+05:00,ACC-1024,ACC-2081,850000
```

Используйте только синтетические данные. Кодировка UTF-8, разделитель — запятая или точка с запятой, объём — до 1 МБ и 1000 операций. ID операции должен быть уникальным внутри файла. Время задаётся в ISO 8601 с часовым смещением или `Z`. Суммы указываются в тенге с точностью до двух знаков после запятой. Полный пример можно скачать на странице «Транзакции» или открыть в [data/demo.csv](data/demo.csv).

## Как оценивается риск

| Правило | Баллы | Условие |
| --- | ---: | --- |
| Новый получатель | 15 | Первая операция по паре счетов в наборе |
| Нетипичная сумма | 35 | От 100 000 ₸ и минимум втрое выше медианы предыдущих 3–10 переводов отправителя |
| Частые переводы | 25 | Три исходящих перевода за 10 минут |
| Быстрая цепочка | 50 | Исходящий перевод посредника в течение 15 минут после поступления на сумму не меньше исходящей |
| Дробление суммы | 40 | Минимум три перевода по одной паре за 10 минут, каждый меньше 100 000 ₸, вместе от 200 000 ₸ |

Баллы суммируются с максимумом 100. От 45 операция попадает на проверку, от 70 риск считается высоким. Расследование объединяет операции, связанные сработавшими правилами, и получает наибольшую оценку риска среди них. Балл помогает выбрать приоритет проверки.

What-if помечает остановленный перевод и последующие операции, связанные правилом цепочки. Для каждого исходящего выбирается ближайшее предшествующее поступление подходящей суммы. Это модель связей по времени и сумме. Оборот включает перевод на каждом затронутом звене цепочки.

## Сценарий проверки

1. На «Обзоре» откройте `FR-001`. Проверьте причины, связанные операции и направления стрелок на графе.
2. В Replay выберите `TX-2041` и нажмите «Смоделировать остановку». Сценарий затрагивает два последующих перевода, `TX-2042` и `TX-2043`. Перейдите к последнему шагу, чтобы увидеть их на графе.
3. Скачайте PDF. Затем откройте `FR-002`, чтобы увидеть пример дробления суммы.
